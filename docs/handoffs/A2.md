# A2 handoff — anomaly detector (M1) and alarm validator (M2)

## What exists
- `prahari/models/anomaly/` (`model.py`, `train.py`): IsolationForest on 12 causal rolling features per (node, minute): 5- and 15-min KPI mean z vs the previous hour (6 KPIs). Baseline: 3-sigma on max|z5|. Name `anomaly_iforest`.
- `prahari/models/validator/` (`model.py`, `train.py`): alarm real-vs-noise. Features: type, severity, node type, vendor, same-node and same-type alarm counts in last 10 min, neighbour alarms in last 5 min, 6 KPI z-scores at alarm time. LogisticRegression baseline, HistGradientBoosting + isotonic calibration. Name `alarm_validator`.
- `prahari/models/_io.py`: shared artifact/card helpers (new file in a shared dir, used by both).
- Artifacts in `artifacts/<name>/<version>/model.joblib` + `<version>.card.json`. Tests: `tests/test_models_classical.py` (6 pass, 18 s; tiny train 10 s).

## How to run
`.venv/bin/python -m prahari.models.validator.train` (~64 s) and `...anomaly.train` (~80 s) on the 90-day DB. Chronological splits from `artifacts/splits.json`. `Makefile train` target not edited (A0/orchestrator should call both).
API: `load(version=None)` -> predictor. `validator.predict({"alarms":[{alarm_id,ts,node_id,alarm_type,severity}], "context_alarms":[...earlier], "kpi_z":{alarm_id:[6]}})` -> `{"results":[{alarm_id,valid_prob,is_valid_pred}], model, latency_ms}`; `predict_window(start,end,settings)` reads DB (no labels) and returns a DataFrame. `anomaly.predict({"kpi":{node:[[6 KPIs] x >=65 min]}})` -> per-node score/is_anomaly/z_max; `predict_window(start,end)` gives max over the window.

## Measured (seed 42, test = last 15% by time)
- Validator (HGB, threshold 0.18 = recall >= 0.98 on val): precision 0.962, recall 0.991, F1 0.976, PR-AUC 0.998, Brier 0.021 (0.020 uncalibrated). At 0.5: P 0.980, R 0.983, F1 0.981. LogReg baseline (thr 0.25): P 0.958, R 0.988, F1 0.973, PR-AUC 0.997, Brier 0.031. 826 test alarms, 78.1% true.
- Trade-off: lowering the threshold to protect true alarms cost ~1.8 pts precision vs 0.5 (about 25 noise alarms pass of 181 in test, derived).
- Anomaly (per node, 5-min grid, 407,640 test rows, 0.79% positive): IForest PR-AUC 0.346, P 0.589, R 0.327, F1 0.421 (threshold from val F1). 3-sigma: PR-AUC 0.193, P 0.147, R 0.312, F1 0.200; sigma tuned on val (4.07) F1 0.317.

## Known gaps
- Anomaly is weak in absolute terms (recall 0.33): target includes KPI-silent affected nodes. Synthetic data; validator is near-ceiling, so expect easier than reality.
- Calibration and threshold both fitted on validation; test numbers are clean.
- Validator needs KPI z-scores and ~10 min of earlier alarms for full accuracy (zeros degrade it); `predict_window` supplies both.
- Anomaly/validator labels read only in `train` (targets). I accidentally ran ruff format/fix over `prahari/models/rca` (formatting only).
