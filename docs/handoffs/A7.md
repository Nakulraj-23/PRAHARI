# A7 handoff — dashboard

## What exists
- `web/`: React 18 + Vite + Tailwind 3 + Cytoscape + Recharts (JS). Pinned versions in `package.json`.
- `src/api.js` is the only API client. `VITE_MOCK=1` serves `fixtures/*.json` (via `@fixtures` alias), `VITE_API_URL` (default http://localhost:8000) otherwise. Mock mode keeps small in-memory state so approve/reject and drift-run change the UI, and records calls in `window.__mockCalls` for tests.
- Views: Live Ops (topology coloured by valid-alarm severity, root candidate ringed, alarm feed with noise greyed + toggle, Inject fault, 3 s polling), Incident (top-3 root bars, fault type, evidence, KPI chart, EN/HI narrative + runbook, governance list, Approve/Reject with user + note), Model health (cards vs baseline, drift status + PSI bars, "Run drift scenario" = POST sim/scenario then drift/run, metrics table), Audit (chronological).
- Loading / empty / error (with Retry) states via `components/ui.jsx` `Async`. Tabs, selects, inputs and buttons are native/ARIA, keyboard-usable.
- `make web` (edited A0's Makefile target only): npm install if needed, then `vite dev` on :5173, mock by default; `VITE_MOCK=0 make web` for the real API.

## Run
`cd web && npm install && PLAYWRIGHT_BROWSERS_PATH=/opt/pw-browsers npx playwright test`

## Measured
- Playwright smoke in mock mode: 4/4 passed (~6.5 s). Covers all four views, noise toggle, inject, EN/HI toggle, approve POSTs `/v1/actions/ACT-0001/approve` with the note, drift run.
- `vite build` succeeds (bundle >500 kB, unsplit warning only).

## Known gaps
- No KPI time-series endpoint in CONTRACTS, so the "KPI chart of the root node" plots `evidence.kpi_deltas` (bar chart), not a time series.
- No latency-table endpoint: Model health shows parsed `/metrics` text instead. Per-model latency is not shown.
- Governance list renders whatever checks the API returns (fixture has 2, not 10); untested against 10 real rows.
- Not tested against the real API (A4 not built); response shapes follow `fixtures/` and `schemas.py`.
- Playwright browser download is blocked in the sandbox; config picks Chromium from `PLAYWRIGHT_BROWSERS_PATH` or `PLAYWRIGHT_CHROMIUM_PATH`. No CI step added.
- No CORS handling on our side: A4 must allow the web origin.

## Contract changes requested
- Add `GET /v1/kpi?node_id=&start=&end=` returning KPI series, so the incident chart can be a real time series.
- Add per-endpoint latency stats (e.g. `GET /v1/models/latency`) or expose them in `/v1/models`.
