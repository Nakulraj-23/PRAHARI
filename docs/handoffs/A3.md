# A3 handoff — RCA graph neural network

## What exists
- `prahari/models/rca/`: `model.py` (`RCAGNN`: input linear + 3 residual GCN layers, hidden 64, dropout 0.2, root head over nodes, mean+max pooled fault head; `normalised_adjacency`; input standardisation lives in buffers so ONNX takes raw X), `baselines.py` (upstream-alarmed, most-alarms), `train.py`, `predictor.py` (`RCAPredictor`, `load`), `__init__.py` (`train`, `load`).
- `tests/test_rca.py`: A_hat on a 3-node graph, overfit 8 incidents to 100%, seed determinism, ONNX parity with a different node count. 4 pass, ruff clean.
- Artifacts: `artifacts/rca_gnn/<version>/{model.pt,model.onnx}`, `<version>.card.json`, `latest` (version file).

## How to run
`python -m prahari.models.rca.train` (needs `make seed` first; uses `prahari_alt.db` beside the main DB for the second topology). Wall time 95 s on 4 CPU cores including 76 s of data building. Predictor: `load().predict({"start": ts, "end": ts})` returns the shared RCA contract (top-5, evidence, latency). Optional payload keys: `features` (node frame), `valid_alarm_count`, `noise_alarm_count`.

## Known gaps
- Top-1 is under the 97% suspicion line but close; data is synthetic. GNN beats MLP by 1 incident of 88, so I cannot claim message passing helps. One seed only.
- Alt top-1 of 100% on 47 incidents is a small sample.
- `valid_alarm_count`/`noise_alarm_count` default to all alarms valid unless A4/A5 pass validator counts.
- `train.py` imports A1's private `_window_features` and has its own chunked graph builder (the stock `build_incident_graphs` ran out of memory on 90 days). A1 may want to chunk it and I would then switch back.
