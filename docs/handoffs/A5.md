# A5 handoff — RCA agent and governance gate

## What exists
- `runbooks/`: 15 markdown runbooks `RB-<FAULT>-<CORE|AGG|EDGE>` (5 faults x 3 tiers), with fault_type/node_types/action/risk metadata and Symptoms/Checks/Remediation/Risk sections.
- `prahari/agent/`: `retrieval.py` (numpy TF-IDF + cosine over sections), `sqlguard.py` + `tools.py` (sql_query, get_rca, search_runbooks, propose_action; errors returned to the model), `llm.py` (none | anthropic | openai_compatible, injectable transport), `templates.py` (en/hi), `agent.py` (`explain(rca, lang, ...) -> AgentOutput`, max 6 steps), `flow.py` (`analyze(rca, engine, ...) -> (AgentOutput, GovernanceReport)`, dependents count, window severity).
- `prahari/governance/`: `policy.yaml`, `checks.py` (abstract `Check`, G1-G10, `REGISTRY`), `redact.py`, `__init__.py` (`evaluate(GovContext) -> GovernanceReport`, `decide`). Checks fail closed on exceptions.
- Tests: `tests/test_agent.py`, `tests/test_governance.py` (47 tests).

## How to run
`.venv/bin/pytest tests/test_agent.py tests/test_governance.py`. Usage: `from prahari.agent import analyze; out, gov = analyze(rca_dict, engine, lang="hi", drift_status="green", recent_actions=[...])`. Provider via `PRAHARI_LLM_PROVIDER` (none|anthropic|openai_compatible), `PRAHARI_LLM_MODEL`, `ANTHROPIC_API_KEY`, `PRAHARI_LLM_BASE_URL`, `PRAHARI_LLM_API_KEY`.

## Known gaps
- anthropic/openai_compatible tested with fake transports only, never a real API; stdlib urllib, no streaming/retry.
- G7 fails on the fixture (`rca_gnn/v1.card.json` does not exist until A3 trains), so fixture decisions are `blocked`. G10 treats unknown severity as needs-human.
- G3 only allows numbers derived from the RCA output (probs as %, counts, KPI deltas); an LLM narrative quoting a window time or other number will be blocked. Narrative redaction is regex-based.
- G9 needs `recent_actions`; `actions` has no created-at column, so A4 must supply it (e.g. from audit_log).
- The sql_query tool's table allow-list includes `actions`/`audit_log`; remove if undesired.
