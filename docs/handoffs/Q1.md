   test alarms. HistGB on all features gets 0.998. Cause: noise alarms ignore KPIs. Fix (A1): give
   ~30% of spurious alarms a real KPI blip, and let low-impact true alarms show almost no KPI change.
2. HIGH: label-pure categories. 9 of 15 alarm types appear in one class only. LOSS_OF_SIGNAL,
   POWER_FAILURE, CONFIG_MISMATCH, HIGH_UTILISATION and UPSTREAM_UNREACHABLE are always true.
   CRC/FAN/NTP/INTERFACE_FLAP are always noise. Critical severity is 331/331 true. Signature types
   also give the fault type away. Fix: let every type and severity appear in both classes.
