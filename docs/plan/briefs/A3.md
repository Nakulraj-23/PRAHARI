# A3 — RCA graph neural network (Sonnet)
Read also: `docs/handoffs/A1.md`. Own: `prahari/models/rca/`.
Task: given an incident window, pick the root-cause node and the fault type.
Input per incident: node feature matrix X (from `build_node_window_features`) and adjacency A of the topology.
Model, pure PyTorch (no torch-geometric): GCN layer H' = ReLU(Â H W), Â = D^-1/2 (A + I) D^-1/2, precomputed. 3 layers with residual connections, hidden 64, dropout. Two heads: node-level logits → softmax over nodes (root), mean+max pooled graph embedding → fault type. Loss = CE(root) + 0.5·CE(fault). Adam, early stopping on validation top-1.
Baselines (required, in the card): (a) most-upstream alarmed node, (b) node with most alarms, (c) an MLP on node features without the graph — this shows what message passing adds.
Metrics on test: root top-1, top-3, fault-type macro-F1; the same on the held-out second topology; breakdown for incidents where the root alarm is missing.
Predictor returns exactly the RCA output contract (top-5 candidates, evidence filled from features).
Also: `export_onnx()` producing `model.onnx` with dynamic node count, and a parity test (max abs diff < 1e-4 vs PyTorch).
Tests: Â is symmetric and correctly normalised on a 3-node toy graph; overfits 8 incidents to 100% (sanity); deterministic under seed.
If top-1 > 97%, suspect leakage or data that is too easy: say so in the handoff rather than celebrating.
Done when: `python -m prahari.models.rca.train` finishes on CPU in under 10 minutes with card + ONNX file.
