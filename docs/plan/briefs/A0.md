# A0 — Scaffold (Sonnet)
Goal: a runnable empty skeleton that every later agent builds inside.
Build:
- `pyproject.toml` (Python 3.11; numpy, pandas, scikit-learn, torch CPU, networkx, sqlalchemy, fastapi, uvicorn, pydantic-settings, pyyaml, onnx, onnxruntime, prometheus-client, httpx, pytest, ruff).
- `prahari/config.py` (Settings), `prahari/db.py` (all tables in CONTRACTS, indexes, `init_db()`), `prahari/schemas.py` (Pydantic models for every API request/response and the RCA + governance contracts).
- Empty packages for every directory in CONTRACTS, each with `__init__.py`.
- `fixtures/*.json`: one realistic example per endpoint, validated against `schemas.py` by a test.
- `Makefile` targets: setup, seed, train, serve, web, test, bench, lint (unbuilt targets print "not built yet" and exit 0).
- `docker-compose.yml` (api, web, postgres), `Dockerfile`, `.github/workflows/ci.yml` (lint + test), `.gitignore`, `docs/EXPERIMENTS.md` header.
- `git init` if needed.
Done when: `make setup && make lint && make test` pass; fixtures validate.
