# A7 — Dashboard (Sonnet)
Own: `web/`. Build against `fixtures/*.json` through a mock mode (`VITE_MOCK=1`); real API at `VITE_API_URL`.
Stack: React + Vite, JavaScript, Tailwind, Cytoscape.js (topology), Recharts (KPIs). Dark, dense, NOC-style UI; no marketing page.
Views:
1. Live Ops: topology coloured by node state, root-cause node ringed, alarm feed with noise alarms greyed and a toggle, "Inject fault" control, polling every 3 s.
2. Incident: top-3 root candidates with probability bars, fault type, evidence, KPI chart of the root node, narrative with EN/HI toggle, cited runbook, governance checklist (10 rows pass/warn/fail), Approve / Reject with note.
3. Model health: model cards (metrics vs baseline), drift status with per-feature PSI bars, "Run drift scenario", latency table.
4. Audit: chronological audit log.
Requirements: loading, empty and error states; keyboard-accessible controls; one API client module; no hard-coded sample data outside mock mode.
Tests: Playwright smoke in mock mode — pages render, approve flow calls the right endpoint.
Done when: `make web` serves the app and all four views work in mock mode.
