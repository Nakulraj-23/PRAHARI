# A9 — Documentation and interview guide (Opus)
Read: `docs/plan/PLAN.md`, all handoffs, model cards, `docs/bench.md`, `docs/EXPERIMENTS.md`; read source where needed to explain it accurately.
Use only measured numbers. Where something was not built or did not work, say so.
Write:
1. `README.md`: what it is, 60-second quickstart, architecture diagram, results table, screenshots, limitations.
2. `docs/ARCHITECTURE.md`: components, data flow, the key design decisions with the alternative that was rejected and why.
3. `docs/INTERVIEW_GUIDE.md` — for a candidate who must defend every line:
   - 30-second and 2-minute pitch; one-paragraph "why I built this for Tech Mahindra" with sources.
   - Walkthrough of each component: what it does, how, why this way, what the code file is.
   - The concepts underneath, explained from first principles: GCN and normalised adjacency (with a worked 3-node example), IsolationForest, gradient boosting, calibration, precision/recall trade-off, PSI and KS (worked example), quantisation, REST semantics, indexing and normalisation of the schema, BFS propagation and its complexity.
   - Results and how to read them; the error analysis from Q2; what failed and what was learned (from EXPERIMENTS.md).
   - Honest limitations: synthetic data, scale, what production would need.
   - Question bank, at least 60 questions with model answers: project-specific, ML fundamentals, DSA/OOP/DBMS tied to this code, system design ("scale this to 100k nodes"), responsible AI, "what would you do differently", and how to answer "was this built with AI tools?" truthfully.
   - JD line → evidence table. Demo script with timings and a fallback if the demo breaks.
   - Company sheet: Orion, VerifAI, Project Indus, AI Delivered Right, the 2026 NVIDIA and Microsoft telecom launches, with links, and 5 questions to ask the interviewer.
   - A 3-day study plan and 5 small exercises the candidate should do by hand in the code (e.g. add an 11th governance check, change the GNN depth and re-run).
Plain language, short sentences, no filler.
