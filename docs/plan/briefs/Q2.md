# Q2 — Model audit (Opus)
Read: handoffs A2, A3, Q1; model cards; then the training code.
Independently re-run evaluation on the test split with your own script and compare with the cards. Report in `docs/handoffs/Q2.md`.
Check:
- Reported metrics reproduce (tolerance stated). Baselines are fair (same split, tuned on validation only).
- No tuning on test; thresholds chosen on validation; calibration checked with a reliability table.
- RCA: results by fault type, by graph distance of the error (how far wrong when wrong), with root alarm missing, on the held-out topology. Is the GNN really better than the no-graph MLP?
- Robustness: drop 30% of alarms, add 50% more noise — how fast does it degrade?
- Error analysis: 10 worst mistakes, with a one-line reason each. This feeds the interview guide.
- ONNX parity.
Add model quality-gate tests to `tests/models/` with thresholds set just below the verified numbers, so CI catches regressions.
